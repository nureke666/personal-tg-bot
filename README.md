# Личный Telegram-бот: задачи, отсчёты, финансы, привычки

Бот только для владельца (`OWNER_ID` из `.env`): остальным он не отвечает. Всё делается кнопками.

- **📋 Задачи.** Что сделать, когда и подробности. Можно поставить несколько напоминаний (в момент, за 15 мин,
  за 1 ч, за 1 день) и повтор: каждый день, по будням, каждую неделю, каждый месяц. Из напоминания задачу
  можно сразу отметить сделанной или отложить на 10 минут, на час или на завтра. По утрам приходит сводка на
  день.
- **⏳ Обратные отсчёты.** Задаёшь тему, дату, время и свой текст. Каждый день в это время бот пишет, сколько
  дней осталось. В тексте можно использовать `{дни}`: «До отпуска {дни}!» превратится в «До отпуска 12 дней!».
  Отсчёт можно сделать **ежегодным** (дни рождения, годовщины): после события он сам переходит на следующий
  год. Чтобы бот не писал весь год, можно выбрать «за 30 дней» или «за 7 дней» до события.
- **💰 Финансы.** Расходы и доходы по категориям, несколько счетов (карта, наличные…) с переводами между ними,
  баланс, отчёты за день, неделю, месяц и год. Лимиты на
  месяц, общий и по категориям: бот предупреждает на 80% и 100%. Выгрузка в Excel и CSV. **Регулярные
  платежи** (аренда, подписки): в день оплаты напоминание с кнопкой «✅ Оплачено», она сама запишет расход.
- **✅ Привычки.** Отметки по дням, серии 🔥, процент за 30 дней, напоминания, вечерний опрос.
  Список на день разделён на **🌅 Утром, ☀️ Днём и 🌙 Вечером** — часть дня выбираешь при создании
  привычки, поменять можно в её карточке. В 06:00 бот присылает этот список и **закрепляет** его
  (вчерашний открепляет): у каждой привычки свой номер, под списком по ряду кнопок `1` `2` `3`… на каждую
  часть дня, нажал — отмечено. Номера идут сверху вниз и не зависят от дня: если привычка сегодня не по
  плану, её номер просто пропускается. Отмечать можно где угодно (в закрепе, в меню,
  из напоминания), закреп обновится сам. Список включён сразу; в ⚙️ Настройках — время,
  выключение и «📤 Прислать сейчас». У привычки с конкретным временем можно
  включить своё напоминание, а вечерний опрос в 21:00 напомнит о том, что не отмечено.
  Есть и **отказы** («🍬 Без сладкого», «🚭 Не курю»): отмечать каждый день не нужно, бот сам считает
  дни без срыва. Если сорвался, жмёшь «💥 Сорвался», счётчик начинается заново, а рекорд и история
  остаются.
- **📊 Итоги.** Сводка по всем разделам за неделю, месяц или год: сколько задач выполнено (и какие),
  процент по каждой привычке, срывы в отказах, доходы и расходы по сравнению с прошлым периодом. Стрелками
  листается в прошлое, хоть на год назад. По воскресеньям в 20:00 итоги недели приходят сами (если за неделю
  что-то было); время и выключение — в ⚙️ Настройках. В календаре привычки видно каждый месяц и можно
  отметить любой прошедший день. Финансовый отчёт тоже листается: «◀ ▶» к соседнему дню, неделе, месяцу,
  году.
- **📜 Журнал.** Последние действия: 10, 25 или 50 за раз, выбираются кнопками. Записи сгруппированы по
  дням, у каждой время. В журнал попадает всё, что меняет данные: новые задачи и операции, выполнения и
  отметки, правки, удаления, срывы, смена настроек. Просмотры экранов не записываются. Хранятся
  последние 200 записей.
- **✍️ Быстрый ввод.** Можно просто написать боту `1500 такси` (или `такси 1500`), и он запишет расход,
  а `+250000 зарплата` запишет как доход. Категорию бот угадывает по прошлым записям с тем же текстом
  и по названиям категорий. Если не угадал, спросит один раз, а в следующий раз запишет сразу. Текст без
  суммы бот предложит сохранить задачей: на сегодня, на завтра, без даты или с датой и временем. Если в тексте
  есть дата или время — «завтра в 10 позвонить маме», «каждый понедельник спортзал в 19», «через 2 часа
  выпить таблетку» — задача ставится сразу.

## Как работают повторы

Повторяющаяся задача переезжает на следующий раз, когда нажимаешь «✅ Выполнено». Каждое выполнение
записывается в историю, поэтому в итогах видно, например, «Зарядка ×5» за неделю. Если не отметил, она
**сама переедет в полночь**, так что напоминание придёт и на следующий день. Если нажать «Сделано» на
напоминании из прошлого раза, бот не отметит по ошибке новый раз и скажет, что тот раз уже прошёл.

## Запуск на ноутбуке

Нужен [uv](https://docs.astral.sh/uv/).

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. `cp .env.example .env` и впиши `BOT_TOKEN=...`.
3. `uv run python -m bot`. В логе должно появиться `Бот @… запущен`.
4. Напиши боту `/start`, он пришлёт твой id. Впиши его в `.env` как `OWNER_ID=...` и перезапусти бота.
5. Снова `/start`: появится меню.

Напоминания приходят, только пока бот запущен. Если бот был выключен, пропущенное придёт один раз при
следующем запуске.

## Запуск на VPS (Docker)

```bash
git clone <репозиторий> tg_bot && cd tg_bot   # или скопируй папку через scp/rsync
cp .env.example .env && nano .env             # BOT_TOKEN и OWNER_ID
mkdir -p data && sudo chown 1000:1000 data    # в контейнере бот работает от uid 1000
docker compose up -d --build
docker compose logs -f                        # должно быть «Бот @… запущен»
```

Бот перезапускается сам (`restart: unless-stopped`). База лежит в `./data/bot.db`.

### Автодеплой

После каждого влитого в `main` PR GitHub Actions прогоняет проверки, копирует код в папку бота на VPS
(`.env`, `data/` и другие свои файлы не трогает), делает копию базы `data/before-deploy.db` и
`docker compose up -d --build`, затем ждёт в логах «Бот … запущен» — иначе прогон красный. Вручную —
Actions → CI → Run workflow.

Выключен, пока в репозитории нет переменной `DEPLOY=on` (Settings → Secrets and variables → Actions →
Variables). Один раз настроить (папка бота на сервере с `docker-compose.yml` и `.env` уже должна быть):

```bash
ssh-keygen -t ed25519 -N "" -f ~/.ssh/tg_bot_deploy                # ключ только для деплоя
ssh-copy-id -i ~/.ssh/tg_bot_deploy.pub <user>@<host>
gh secret set VPS_SSH_KEY < ~/.ssh/tg_bot_deploy
ssh-keyscan <host> | gh secret set VPS_KNOWN_HOSTS
gh secret set VPS_HOST --body <host>
gh secret set VPS_USER --body <user>                               # в группе docker
gh secret set VPS_PATH --body /home/<user>/tg_bot                  # абсолютный путь
```

## Бэкап

Каждую ночь в 03:00 бот без звука присылает владельцу файл базы `bot-ГГГГ-ММ-ДД.db`. Время меняется, бэкап
выключается, и свежую копию можно прислать сразу: ⚙️ Настройки → 💾 Бэкап базы. Первый бэкап после обновления приходит сразу.

Восстановление: `docker compose down`, положи файл из Telegram вместо `data/bot.db` (владелец — uid 1000),
`docker compose up -d`.

**Не запускай бота одновременно на ноутбуке и на VPS с одним токеном.** Telegram отдаёт сообщения только
одному из них. Перед переездом останови локальный и перенеси `data/bot.db`, если хочешь сохранить данные.

## Разработка

```bash
uv run pytest            # тесты: логика, планировщик, сквозные сценарии через Dispatcher
uv run ruff check .      # линтер
uv run ruff format .     # форматирование
```

На каждый PR GitHub Actions гоняет тесты, линтер и проверку форматирования (`.github/workflows/ci.yml`).

Устройство:
- `bot/handlers/` — обработчики по разделам.
- `bot/views/` — тексты и клавиатуры экранов.
- `bot/repo/` — SQL.
- `bot/services/` — время, планировщик, отчёты, выгрузка, серии, бэкап.
- Журнал действий пишут обработчики: `journal.add(db, user_id, "✅ …")` после каждого изменения данных.

Планировщик раз в 30 секунд берёт из БД всё, чему пора сработать. Время хранится в UTC, показывается в
поясе из настроек.
