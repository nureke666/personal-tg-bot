# Конвенции репозитория

Единый свод правил для людей и для агент-сессий. Всё, что касается «как здесь принято», живёт
здесь. Claude Code читает этот файл через `CLAUDE.md` (`@AGENTS.md`), остальные агенты — сами.

Личный Telegram-бот одного владельца: задачи с напоминаниями, обратные отсчёты, финансы, привычки,
итоги и журнал. Один процесс: aiogram принимает апдейты long polling, рядом в том же процессе
крутится планировщик, всё состояние — в одном файле SQLite.

## Стек

- `bot/` — Python 3.12, aiogram 3, aiosqlite, pydantic-settings, openpyxl (выгрузка в Excel).
- `tests/` — pytest + pytest-asyncio (`asyncio_mode = "auto"`), линтер и форматтер — ruff.
- Пакетный менеджер — `uv`, зависимости зафиксированы в `uv.lock`. Не pip и не poetry.
- Прод — Docker Compose на VPS (`Dockerfile`, `docker-compose.yml`), база в `./data/bot.db`.

## Команды

- `uv sync` — поставить зависимости в `.venv`.
- `uv run python -m bot` — запустить бота; нужен `.env` с `BOT_TOKEN` и `OWNER_ID` (образец — `.env.example`).
- `uv run ruff format .` — отформатировать; в воротах только проверка `--check`.

## Ворота

Изменение считается готовым, когда прошло из корня репозитория:

```bash
uv run ruff check . && uv run ruff format --check . && uv run pytest
```

Запускать голой командой и смотреть **реальный код возврата**. `… | tail` вернёт код возврата
`tail`, а не проверки; «зелено» без exit code 0 ничего не значит. Внутри рабочего цикла хватает
узкой петли (`uv run pytest tests/test_flows.py -k <имя>`), перед коммитом — ворота целиком.
Те же три шага гоняет CI (`.github/workflows/ci.yml`) после `uv sync --locked`.

Предусловие — `uv sync`. Токен и сеть тестам не нужны: Bot API подменён записью вызовов
(`tests/conftest.py:RecordingSession`), база — `:memory:`.

## Инварианты

Эти свойства закрыты тестами и не ослабляются. Тест, который начал мешать, — повод обсудить
изменение, а не повод его переписать.

| Инвариант | Где держится |
| --------- | ------------ |
| Бот отвечает только владельцу (`OWNER_ID`); без `OWNER_ID` только подсказывает id | `bot/middlewares/owner.py:OwnerMiddleware`; тесты `test_stranger_is_ignored`, `test_without_owner_bot_tells_user_id` |
| Планировщик пишет только владельцу, чужие события не копятся; без `OWNER_ID` ничего не трогает | `bot/services/scheduler.py:Outbox`; тесты `test_scheduler_sends_nothing_from_other_users_data`, `test_scheduler_without_owner_waits_for_it` |
| Напоминание приходит ровно один раз, после простоя — одно, с пометкой «с опозданием» | `bot/services/scheduler.py:task_reminders`; тесты `test_reminder_is_sent_exactly_once`, `test_after_downtime_one_late_reminder` |
| «Сделано» на напоминании прошлого раза не отмечает новый раз повторяющейся задачи | `bot/handlers/tasks.py:reminder_action`; тест `test_snooze_and_stale_occurrence` |
| Повтор не уезжает в прошлое, месячный держит день месяца | `bot/services/timeutil.py:advance_repeat`; тесты `test_advance_repeat_never_lands_in_the_past`, `test_monthly_repeat_keeps_anchor_day_after_short_month` |
| Смена часового пояса сохраняет локальное время расписаний | `bot/services/planning.py:reschedule_all`; тест `test_timezone_change_keeps_local_times` |

## Что требует согласования

Меняется отдельной задачей, с описанием причины и последствий, а не по ходу другой работы:

- **Схема БД** — `bot/db.py:MIGRATIONS`, номер применённой лежит в `PRAGMA user_version`.
  Применённая миграция не редактируется и не удаляется; изменение приезжает следующим элементом
  списка, с тестом на перенос старых данных (образцы — `tests/test_scheduler.py:test_migration_*`).
- **`bot/callbacks.py`** — префиксы и поля `CallbackData` зашиты в кнопки уже отправленных сообщений
  (закреп привычек, напоминания); после переименования старые кнопки перестают работать.

## Границы

- В `main` напрямую не пушим — только PR. Влитый в `main` PR сразу уезжает в прод: job `deploy` в
  `.github/workflows/ci.yml` копирует код на VPS и перезапускает контейнер.
- Не запускать бота локально с боевым токеном, пока он работает на VPS: Telegram отдаёт апдейты
  только одному экземпляру.
- `data/bot.db` — живые данные владельца, в git не попадает.
- Секреты в репозиторий не попадают никогда. В git живёт только `.env.example`; `.env` лежит
  рядом и проигнорирован.

## Сгенерированные файлы

Руками не правятся: их перезапишет ближайший прогон генератора. Правится источник.

- `uv.lock` → `uv lock` (или `uv add` / `uv remove`; источник — `pyproject.toml`)

## Формат коммитов

Сложившийся формат — одна фраза по-русски о том, что изменилось для пользователя, без префикса типа;
после squash-мерджа GitHub дописывает номер PR:

```
Журнал действий: последние 10, 25 или 50 кнопками (#3)
Привычки по частям дня: утром, днём, вечером
```

Один коммит — один завершённый шаг; репозиторий остаётся рабочим после каждого.

## Язык

- **Комментарии, docstring и сообщения коммитов** — русский. Комментарий пишется только для
  неочевидного «почему».
- **Пользовательские тексты** — русский, на «ты», с эмодзи-маркерами разделов, как в `bot/handlers/common.py:HELP`.
- **Документы репозитория** (`.md`) — русский.

## Журнал изменений

Всё, что видно снаружи, пишется в `## [Unreleased]` [CHANGELOG.md](CHANGELOG.md) **в том же
коммите**, что и правка. Задним числом журнал не восстанавливается. Решение, выбранное из
нескольких вариантов, — ADR в [docs/adr/](docs/adr/).

## Ссылки на код в документах

Называем символ — `путь/до/файла:имя_функции`, а не номер строки: номер уезжает при первой
правке выше по файлу, молча и без конфликта при мерже.

## Карта ключевых мест

| Что | Где |
| --- | --- |
| Сборка диспетчера; порядок роутеров важен (меню → разделы → быстрый ввод → fallback) | `bot/__main__.py:build_dispatcher` |
| Кто может писать боту | `bot/middlewares/owner.py:OwnerMiddleware` |
| Схема и миграции БД | `bot/db.py:MIGRATIONS` |
| Всё, что бот шлёт сам по расписанию | `bot/services/scheduler.py:tick` |
| Обработчики по разделам / тексты и клавиатуры экранов / SQL | `bot/handlers/`, `bot/views/`, `bot/repo/` |
| Данные кнопок | `bot/callbacks.py` |
| Состояние мастеров (FSM) в SQLite | `bot/storage.py:SQLiteStorage` |
| Время: UTC в базе, локальное на экране, повторы | `bot/services/timeutil.py` |
| Быстрый ввод «1500 такси» | `bot/services/quick.py`, `bot/handlers/quick.py` |
| Сквозные тесты через настоящий Dispatcher | `tests/conftest.py:Harness` |
